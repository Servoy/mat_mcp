MAT MCP Server — Eclipse Update Site

This is a p2 update site for the MAT MCP Server feature: it runs an MCP server inside Eclipse Memory Analyzer (MAT) so an AI agent can analyze the heap dump you have open, over HTTP at http://127.0.0.1:8923/mcp.

Install into MAT

  1. In MAT: Help → Install New Software…
  2. Paste this update-site URL into Work with:

    loading…

  3. Select MAT MCP Server, finish the wizard, and restart MAT.
  4. On restart the server auto-starts; a green M toolbar icon means it is listening (grey = stopped; the icon also toggles it).

Requires MAT 1.17.x. Source and docs: github.com/Servoy/mat_mcp.
